Emailuri profesionale pentru Librava

Emailurile vor pleca de la Librava <noreply@librava.store>, cu designul site-ului și în limba clientului (RO, IT, EN, FR, DE, ES).

1Adaugă domeniul în Resend

  1. Intră pe resend.com (contul pe care îl folosești și la BizScan) → Domains → Add domain.
  2. Domain: librava.store · Region: Ireland (eu-west-1) → Add.
  3. Resend îți arată 3–4 înregistrări DNS (MX, TXT pentru send și TXT resend._domainkey). Lasă pagina deschisă.

2Pune înregistrările în Register.it

  1. Register.it → librava.store → DNS e servizi → Gestione DNS (modifica record).
  2. Adaugă fiecare înregistrare exact cum o arată Resend: tip, nume (ex. send, resend._domainkey), valoare.
  3. Nu șterge înregistrările existente A/CNAME ale site-ului (cele spre GitHub).
  4. În Resend apasă Verify DNS records. Poate dura de la câteva minute la câteva ore până apare „Verified”.

3Creează cheia de trimitere în Resend

  1. Resend → API Keys → Create API key.
  2. Name: Librava Supabase · Permission: Sending access · Domain: librava.store → Add.
  3. Copiază cheia (începe cu re_). O pui doar în Supabase la pasul 4, nu în chat.

4Supabase → Authentication → Emails → SMTP Settings

Activează Enable custom SMTP și completează:

Sender emailnoreply@librava.store
Sender nameLibrava
Hostsmtp.resend.com
Port465
Usernameresend
Passwordcheia re_… de la pasul 3
Minimum interval30 secunde (lasă cum e)

Apasă Save. Apoi la Authentication → Rate Limits pune „Rate limit for sending emails” la 100 pe oră.

5Supabase → Authentication → Emails → Templates

Pentru fiecare dintre cele 3 emailuri de mai jos: deschide tab-ul cu același nume în Supabase, înlocuiește Subject și conținutul de la Source (șterge tot ce era), apoi Save.

Linkurile din emailuri duc direct pe librava.store și funcționează pe orice telefon sau calculator, nu doar pe cel unde s-a făcut contul.
