Digital Literacy Guide: Everyday Skills to Practice First

By the Librava editors · Updated 2026-10-31

A digital literacy guide for everyday tasks: navigating websites, managing files, checking messages and practicing safely on your phone or computer.

In this guide
  1. Begin with one useful task
  2. Understand tabs, addresses and links
  3. Give downloads a place you can find
  4. Build a repeatable safety check

Begin with one useful task

Choose something you want to do independently, such as finding an appointment email, reading an ebook or downloading a receipt. Write the steps on paper and practice using a harmless example. Learn the task on the device you normally use rather than trying to master a phone, tablet and laptop at once.

For each task, record where you start, what success looks like and how to return to the previous screen. Keep instructions short enough to follow while looking at the device.

Understand tabs, addresses and links

A browser tab is an open page, the address bar shows its address, and a search box helps you find something. Check which one you are using before typing. If a link takes you somewhere unexpected, stop and inspect the address instead of continuing automatically.

Practice opening a trusted website, opening a second tab, switching between them and closing only the tab you no longer need. Mozilla provides a free introduction to browsing the web if you want more background.

Give downloads a place you can find

Download one non-sensitive practice file and locate it in your device’s downloads area. Note its name and extension. Create a folder with a clear purpose, such as Receipts or Reading, and practice moving a copy there. Open it again from the folder before deleting any original.

When a task involves an important document, keep a backup and make sure you understand which copy you are editing. Avoid sharing screenshots that expose personal details when asking for help.

Build a repeatable safety check

Before replying to an unexpected message or opening an attachment, pause and verify who sent it using a contact route you already trust. Do not give anyone your password or verification codes. If the message creates urgency, step away long enough to check the request independently.

Practice these habits with a family member using ordinary, non-sensitive examples. For smartphone basics, explore our guide to using your phone more intentionally and the smartphone book linked below. For building a website, use the separate learn HTML and CSS guide.
